Niveaux des utilisateurs et documents

Inscription individuelle : niveau scolaire, universitaire ou technique et professionnel, avec classe/année/spécialité facultative. Les anciens comptes restent compatibles, sans attribution automatique. Le responsable d’établissement peut définir ou modifier le niveau de ses élèves.

Documents : Public cible dans Ajouter un livre, Modifier et import EPUB multiple (niveau commun au lot). Le champ libre classe/spécialité est conservé. Les documents existants sont considérés tous niveaux jusqu’à leur classement.

Accueil et Recommandés : priorité aux ouvrages du niveau de l’utilisateur, complétés par les ouvrages tous niveaux. Les autres niveaux restent accessibles dans le catalogue. Le rapprochement utilise le niveau général ; la classe/spécialité reste descriptive.

Déployer l’intégralité du projet, version 1.6.2, sans remplacer les données persistantes.
