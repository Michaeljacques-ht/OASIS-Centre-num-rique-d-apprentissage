# Téléchargements — 1.8.1
Dans les listes Catalogue, Ressources ou Multimédia, utiliser Restreindre téléchargement pour un élément, puis Autoriser téléchargement pour revenir en arrière. Les éléments existants restent autorisés par défaut. Les droits des administrateurs délégués s’appliquent aux mêmes domaines.

Les boutons Télécharger et Ouvrir du lecteur PDF sont retirés quand le livre est restreint, ceux des médias aussi. Le lecteur EPUB garde la lecture en ligne. Le serveur bloque les accès directs aux fichiers PDF/EPUB/médias restreints pour les lecteurs sauf les requêtes de consultation en ligne. Le bibliothécaire conserve son accès de gestion. Ces restrictions complètent les contrôles d’abonnement existants.

Ceci n’est PAS un DRM : la lecture transmet les données au navigateur. Une personne utilisant les outils réseau peut reproduire une requête de lecture, sauvegarder les données ou effectuer des captures. Le paramètre lecture=1 distingue la consultation du téléchargement proposé par OASIS, sans garantir une protection contre la récupération technique. Un fichier déjà téléchargé ne peut pas être révoqué.

Les ressources documentaires sont du texte, des images et/ou des liens externes. Restreindre retire le lien externe de la réponse publique et de l’interface, tout en laissant le contenu local consultable. OASIS ne peut pas bloquer le téléchargement sur le site externe ni effacer un lien déjà connu. Les images visibles restent récupérables.

Tests HTTP : modification réservée aux administrateurs, accès direct EPUB restreint 403, lecteur 200, réautorisation 200, liens externes masqués aux lecteurs, validation des paramètres. Pas de test visuel mobile ni DRM.
