# Navigation établissement — 1.7.6
Les liens Bibliothèque et Explorer le catalogue OASIS ouvrent /?vue=bibliotheque. Le démarrage de l’application respecte cette destination au lieu de renvoyer les responsables vers /ecole. Les liens directs vers un livre sont également conservés. Une connexion ordinaire de responsable continue d’ouvrir l’espace établissement. Le lien établissement du catalogue permet d’y revenir.

Aucun changement de rôle, droits d’accès, abonnement ou données. Déployer le projet complet sans remplacer data. Vérifier /api/version : 1.7.6 puis recharger la page établissement.
